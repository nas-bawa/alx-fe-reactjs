# GitHub User Search (React + TailwindCSS)

A simple React application styled with TailwindCSS that allows users to search for GitHub profiles using the GitHub API.

## 🚀 Features
- Search GitHub users by username
- Display user avatar, name, and profile link
- Responsive UI styled with TailwindCSS
- Error and loading states
