# Tailwind React Integration

This project demonstrates how to set up and configure Tailwind CSS in a React application using Vite.

## Setup
- Created with Vite (`npm create vite@latest tailwind-react-integration -- --template react`)
- Tailwind CSS installed and configured with the Vite plugin
- Utility-first styling applied to React components

## Run the project
```bash
npm install
npm run dev
